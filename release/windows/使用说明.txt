Bilibili 收藏集卡片 ID 工具
=============================

【开始使用】

1. 请先完整解压 ZIP，不要直接在压缩包里运行。
2. 双击“启动工具.bat”。
3. 第一次使用请选择 [1]，用哔哩哔哩手机客户端扫码登录。
4. 选择 [2]，输入收藏集名称，然后根据数字提示操作。
5. 完整抓取可能需要 20～30 分钟，可以中断后继续。

【文件说明】

程序会在当前文件夹生成：

  .env                 登录凭据，请勿发送给别人
  data\garb.sqlite3    抓取进度和卡片数据

升级版本时，请保留这两个文件（或整个 data 文件夹）。

【Windows 安全提示】

本程序暂未购买代码签名证书。Windows 可能显示“已保护你的电脑”：

  点击“更多信息” → “仍要运行”

请只从项目官方 GitHub Release 页面下载程序。

【隐私与使用边界】

工具只处理接口返回的公开收藏信息，不会绕过用户的隐私设置。
请勿将结果用于骚扰、画像或其他侵害用户权益的用途。
